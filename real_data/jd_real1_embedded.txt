# 来源说明：本 JD 由以下真实在招岗位的原文句子拼合（2026-10-07 检索），仅用于词库评估：
# hrcampus.cn《校招-初级嵌入式软件工程师》、云济松嵌入式软件工程师岗、18aicai.com 高级嵌入式软件开发工程师
工作职责：
1. 负责产品嵌入式软件开发（STM32 F1/F4 系列），基于智能控制器硬件平台进行固件开发；
2. 编写 GPIO、ADC、PWM 等外设驱动，完成串口、定时器等硬件驱动开发；
3. 基于 FreeRTOS 进行任务调度与调优，实现通信协议与 TCP/IP 应用层功能；
4. 负责全数字仿真产品软件代码测试与技术文档的总结和编写。
任职要求：
1. 精通 C 语言，了解 C++，能编写高质量代码；
2. 熟悉 STM32 或其他至少一款 MCU，熟悉 MCU 内部运行原理，熟悉 Cortex-M3 处理器架构；
3. 有 FreeRTOS、μC/OS-II 或 RT-Thread 等嵌入式操作系统使用经验；
4. 熟悉 UART、SPI、I2C、CAN 等常用通信接口，熟悉 TCP/IP 协议及常用应用层协议；
5. 良好的硬件知识基础，能读懂硬件原理图。
